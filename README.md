# task-planner

Android 任务计划应用：添加任务并指定开始时间、截止日期、优先级等，保存后**自动写入系统日历日程**，并按策略**自动挂提醒**（如「截止前 1 小时」），到期通过系统通知提醒。

> 状态：开发中。Kotlin + Jetpack Compose 原生实现。

## 功能特性

- **任务管理**：标题、描述、开始时间（可选）、截止时间、优先级（0~100 连续值，蓝→红渐变）、状态（待办 / 进行中 / 完成）、标签
- **列表视图**：未定时 / 已逾期 / 今日 / 近期 / 已完成 分组，按截止时间 + 优先级排序
- **搜索与筛选**：标题/描述/标签关键词；状态、优先级、标签 chips 过滤
- **重复任务**：每天 / 每周 / 每月 / 自定义 N 天；滚动预生成保底「未来始终有一条」，完成即续期
- **日历集成**：任务自动同步到系统日历（默认创建专属日历「Task Planner」，可在设置改选其他日历）；增/改/删全量跟随；完成任务事件保留并加 ✓ 前缀
- **自动提醒双通道**：应用自有精确闹钟（主通道，ColorOS 精确）+ 日历事件提醒（兜底通道）；提醒预设可自定义（天/小时/分钟组合）；开机/改时间/改时区自动重排
- **桌面小组件**：今日 + 近期任务列表，点条目直达任务
- **状态流转**：截止时间已过且未完成 → 自动标记为已逾期

## 技术栈

- Kotlin + Jetpack Compose（Material 3），MVVM
- Room 数据库（本地单一事实源，日历为投影）
- Calendar Provider（专属日历 + 事件/提醒写入）
- AlarmManager（setAlarmClock 精确通道）+ BroadcastReceiver + 通知渠道
- RemoteViews 桌面小组件
- minSdk 26（Android 8.0）/ 单元测试 JUnit

## 构建

```bash
# 需要 JDK 21 与 Android SDK；与 keyforge 同一套本机构建链
gradle assembleDebug   # 或在 Android Studio 中打开
```
